Loja de Games – Projeto Backend com Spring Boot

A Loja de Games é um projeto backend desenvolvido em Java com Spring Boot, contendo um CRUD completo para gerenciamento de jogos.

Foi implementado Spring Security para autenticação de usuários, garantindo acesso seguro aos endpoints. Por regra de negócio, a funcionalidade de exclusão (DELETE) foi desativada. O projeto demonstra práticas essenciais de APIs REST e segurança no desenvolvimento backend.

API Farmácia – Backend em Java com Spring Boot

Este projeto é uma aplicação backend desenvolvida em Java com Spring Boot, criada para oferecer uma API REST completa para o gerenciamento de clientes, produtos e categorias de uma farmácia.

A solução foi pensada para organizar e automatizar processos internos, facilitando o controle de estoque, a categorização de itens e o acesso rápido a informações essenciais sobre os produtos.

🌦️ Aplicativo de Clima – Open Meteo

Este projeto é um aplicativo simples de consulta climática, desenvolvido em HTML, CSS e JavaScript, que permite ao usuário pesquisar informações meteorológicas pelo nome de qualquer cidade.

A aplicação consome a API pública Open-Meteo para obter coordenadas (latitude e longitude) e apresentar dados de clima em tempo real, como temperatura e condições atuais.

📘 Site Institucional – BluePeak Agency

A BluePeak Agency é uma agência digital fictícia criada para fins de estudo. Este repositório apresenta o desenvolvimento de seu site institucional, construído inteiramente com HTML5 e W3.CSS.
